Notion Sites を独自ドメインで公開

Worknot は、Notion Sites で公開したページを独自ドメインで配信する Cloudflare Worker のスクリプトを生成します。読みやすい URL、SEO メタデータ、アナリティクスにも対応しています。

  • MIT ライセンス
  • お使いの Cloudflare アカウントで動作
  • Notion の変更を毎日チェック

Worknot でできること

各機能は下のジェネレーターで設定できます。Worknot は、Cloudflare と Notion のパートナーである Classmethod (Europe) GmbH がメンテナンスしています。

独自ドメインと読みやすい URL

Notion Sites のページを独自ドメインで配信し、/about や /blog のような読みやすいパスに割り当てられます。

SEO メタデータ

ページタイトル、説明文、Open Graph タグ、JSON-LD、hreflang、sitemap.xml、RSS フィードを設定できます。

アナリティクス

Notion のページを変更せずに、Google Analytics 4 や Facebook Pixel を追加できます。

画像の最適化

Cloudflare Image Transformations で、Notion の画像をエッジでリサイズ、変換、圧縮します。

ブランディングとカスタムコード

カスタム CSS と JavaScript、Google Fonts のフォント、ファビコン、ヘッダー HTML、カスタム 404 ページを追加できます。

毎日の互換性チェック

毎日 06:00 UTC に Notion のクライアントコードを自動でチェックし、変更があれば GitHub に Issue を作成します。

使い方

Notion Sites で公開したページと、DNS を Cloudflare で管理しているドメインが必要です。

  1. ページを公開する

    Notion で「共有」を開いて「公開」を選び、ページの notion.site の URL をコピーします。

  2. スクリプトを生成する

    下のフォームにドメインと Notion の URL を入力し、必要に応じて Pretty Link やオプションを設定して、スクリプトをコピーします。

  3. Worker をデプロイする

    Cloudflare のダッシュボードで Worker を作成し、コードをスクリプトに置き換えてデプロイします。

  4. ドメインを接続する

    Worker にドメインをカスタムドメインとして追加します。これで Notion Sites のページが独自ドメインで表示されます。

Worker スクリプトを生成

スクリプトは入力に合わせてブラウザー内で生成され、設定内容はどこにも送信されません。フォームは英語表記です。

よくある質問

Worknot は無料で使えますか？

はい。Worknot は MIT ライセンスのオープンソースです。Worker を動かすには Cloudflare のアカウントが必要です。Notion Sites のページを初めて開くと Worker へのリクエストが約 700 件発生するため、Workers Free プラン（1 日 100,000 リクエスト）は小規模なサイト向けです。継続的にアクセスがあるサイトでは Workers Paid をお使いください。

Notion の有料プランは必要ですか？

いいえ。Notion Sites で Web に公開したページであれば利用できます。Notion の独自ドメイン機能は使用しません。

Notion のクライアントが変更されたらどうなりますか？

GitHub Actions のワークフローが毎日 06:00 UTC に Notion のクライアントコードのチェックとテストサイトの表示確認を行い、変更を検出すると Issue を作成します。修正がリリースされたら、このページでスクリプトを生成し直し、Worker を再デプロイしてください。

Worknot は設定やコンテンツを保存しますか？

いいえ。ジェネレーターはすべてブラウザー内で動作し、設定内容をどこにも送信しません。サイトへのアクセスは、お使いの Cloudflare アカウントの Worker を経由します。

Worknot と Fruition の関係は？

Worknot は Stephen Ou 氏が開発した Fruition のフォークとして始まりました。現在は Classmethod (Europe) GmbH がメンテナンスし、最新の Notion Sites に対応させています。
